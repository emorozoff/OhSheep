# OhSheep

Приложение для подсчёта овец перед сном, собранное по мотивам сцены из мультсериала.

Овца стоит в центре экрана. Ты вводишь её номер на цифровой клавиатуре и жмёшь стрелку —
овца перепрыгивает влево за кадр, а справа приходит следующая. Ошибся с числом — овца
тяжело вздыхает и остаётся на месте. Чем больше насчитал, тем сильнее она вымотана;
на сотой овце она засыпает сама.

## Как запустить локально

Сборки нет — это статические файлы. Нужен любой локальный сервер (через `file://`
не заработают ES-модули и service worker):

```bash
python3 -m http.server 8099
# открыть http://127.0.0.1:8099/
```

## Как выложить по ссылке

В настройках репозитория: **Settings → Pages → Source: Deploy from a branch**,
ветка `claude/sheep-counting-app-51gspm` (или `main` после слияния), папка `/ (root)`.
Все пути в проекте относительные, так что подпапка вида `/OhSheep/` ничего не сломает.

## Что внутри

| Файл | Зачем |
|---|---|
| `index.html` | разметка экрана: небо, холм, шапка, поле ввода, клавиатура, меню |
| `src/styles.css` | вся визуальная часть и анимации |
| `src/sheep.js` | овца целиком собирается в SVG программно |
| `src/app.js` | игровой цикл, ввод, счёт, сохранение, размеры |
| `src/audio.js` | звук синтезируется через Web Audio, без внешних файлов |
| `sw.js` | офлайн-кэш |

Внутренние размеры считаются от переменных `--u` и `--v` — это 1% ширины и высоты
экрана, их выставляет `app.js` через `ResizeObserver`. Поэтому вёрстка одинаково
работает и во весь экран на телефоне, и внутри нарисованного телефона на десктопе.

Овца в `src/sheep.js` строится генератором `scallop()`: точки садятся на эллипс,
между ними рисуются дуги, выгнутые наружу — получается «облачная» шерсть с одним
общим контуром. Все пропорции собраны в объекте `C` в начале файла.

Звуки в `src/audio.js` синтезируются на месте: блеяние — это пила с вибрато через
две форманты, вздох — шум с падающим полосовым фильтром, сверчки — короткие импульсы
узкополосного шума. Ни одного медиафайла, приложение весит считанные килобайты.

## Управление с клавиатуры

`0`–`9` — цифры, `Enter` — подтвердить, `Backspace` — стереть, `Esc` — очистить поле.

## Оговорка

Фанатская поделка, вдохновлённая сценой из мультсериала. Никакого отношения
к правообладателям не имеет, названия и персонажи не используются.
